# 亚马逊商品信息采集 Skill

根据亚马逊商品链接或 ASIN，整理指定商品及颜色变体的信息，下载可获取的商品图片和视频，并生成 HTML 商品信息页。

## 输入

- 亚马逊商品链接或 ASIN；可指定站点、颜色变体和输出目录。
- 未指定颜色时，根据商品页面和任务上下文确认要采集的变体。

## 处理过程

1. 通过浏览器打开商品详情页，确认 ASIN 和颜色变体，读取标题、颜色、五点描述、产品描述及 Product information 的实际字段，包括 Brand Name。
2. 展开折叠的商品参数，去除导航按钮、价格反馈、退货政策等页面交互文字；保留商品原文、来源链接及原有拼写。
3. 根据页面图片数据识别主图和副图，优先获取高清图片；检查图片与指定商品及变体的对应关系。采集 Product description 中的 A+ 图片及 Customer photos and videos 中可获取的评论图片，并区分商品视频与广告。
4. 对照标题、描述和参数，记录尺寸、颜色、材质或数量等冲突，列出原始数值和出处；无法获取的信息或媒体如实标注。
5. 验证输出文件存在且非空，将整理结果写入 HTML 页面。

## 输出

默认按 ASIN 创建商品目录；可在任务中指定其他位置。实际文件数量以页面内容和可访问情况为准。

```text
ASIN/
├── ASIN.html         # 商品信息与发现的问题
├── 主图.jpg
├── 副图-01.jpg
├── 副图-02.jpg
├── A+图片/         # 产品描述中的图片
├── 评论图片/       # 可获取的评论图片
└── 商品视频.mp4     # 页面有视频且可下载时
```

HTML 页面包含来源、标题、颜色、五点描述、产品描述、商品参数和“发现的问题”。图片及视频的格式依实际资源而定。

## 使用与依赖

将本仓库作为技能目录安装到支持 `SKILL.md` 的工具中，提供商品链接或 ASIN，并说明目标颜色和所需输出。技能使用 [web-access](https://github.com/eze-is/web-access) 访问浏览器，需先安装和配置；`SKILL.md` 中的 web-access 路径应按实际安装位置调整。部分页面可能需要登录或验证，商品资料和媒体能否获取取决于页面访问情况。
